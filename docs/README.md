# Documentation

Authoritative documentation for the AI TruthLens platform.

## Structure
- `architecture/` — system design, data flow, and service boundaries
- `api/` — API contracts between frontend, backend, and AI backend
- `setup/` — local development and onboarding
- `environment/` — environment variables and runtime configuration notes
- `deployment/` — production deployment guidance

Keep docs in sync with the three-service architecture (frontend, backend, ai-backend).
