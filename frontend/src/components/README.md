# Components

Reusable React UI building blocks for AI TruthLens.

## Structure
- `common/` — shared presentational components
- `ui/` — primitive UI elements
- `auth/` — authentication-related UI
- `detection/` — multimodal detection UI
- `reports/` — report visualization components
- `history/` — detection history UI
- `layout/` — section-level layout pieces used inside pages
